# Expense Tracker

## About

This is a simple SQL-based Expense Tracker project created using MySQL. It is designed to store and organize expense records and make it easier to manage financial data.

## Features

* Add expense records
* Store expense categories
* Track expense amounts
* Store dates and descriptions
* Retrieve and organize expense data using SQL queries

## Technologies Used

* MySQL
* SQL

## Purpose

This project was created as a beginner database project to practice SQL, database management, and organizing real-world financial data.
